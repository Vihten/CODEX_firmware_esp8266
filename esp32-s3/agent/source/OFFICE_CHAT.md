# Офісний чат

## Перше підключення

1. Оновіть прошивку контролера через його вебсторінку.
2. На вебсторінці контролера відкрийте **Агенти → Підключення**, виберіть потрібний ПК і натисніть **Оновити** один раз. Залиште ПК увімкненим. Для сумісних старих версій контролер спочатку запропонує проміжне оновлення, а потім версію з чатом. Завершення підтверджує сам агент після запуску.
   Якщо картка вказує на необхідність ручного оновлення, розпакуйте `bootstrap.zip` на цьому ПК та запустіть `update_codex_lan_agent.cmd` з облікового запису Windows, у якому працює агент. Для першого встановлення використайте `install_codex_lan_agent.cmd`.
3. Біля годинника Windows відкрийте приховані значки. Правою кнопкою натисніть **Офісний чат → Підключити чат**.
4. Скопіюйте ключ із вікна агента й натисніть **Відкрити форму контролера**. Якщо браузер попросить увійти, увійдіть і повторно відкрийте форму з вікна агента. Звірте ідентифікатор ПК, вставте ключ і підтвердьте підключення. Звичайний перезапуск контролера зберігає цю прив’язку.

## Повідомлення

Натисніть значок чату лівою кнопкою. На схемі кабінету виберіть один або кілька столів. Ваше місце позначене **Ви**. Щоб текст побачили на загальній матриці, виберіть також **Табло**. Табло можна вибрати й окремо.

Натисніть **Написати**, введіть текст і натисніть **Надіслати**. Лічильник показує розмір тексту в байтах UTF-8. Максимум для одного повідомлення становить 512 байтів.

На вибраних ПК повідомлення з’явиться справа внизу. Прочитати його знову можна через **Отримані повідомлення** в меню значка. На табло текст прокручується з іменем відправника. Під час пріоритетної індикації прокручування чекає.

Позначка про чергу означає, що агент підготував відправлення. Контролер тримає прийняті повідомлення до десяти хвилин. Перезапуск очищає чергу на контролері. Якщо доставку не підтверджено, у меню значка можна відновити чернетку й перевірити адресатів перед повторним надсиланням.

Чат призначений для довіреної локальної мережі. Контролер перевіряє підписи запитів, а текст передається через HTTP без шифрування.
