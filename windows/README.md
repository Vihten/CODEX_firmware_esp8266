# Хаб агентів для Windows

[Завантажити хаб](agent-hub/agent-hub.zip) · [Завантажити Windows-агент для першого підключення](agent/bootstrap.zip) · [Інструкція](agent-hub/source/README_UK.md)

На ПК оператора розпакуйте архів хаба та запустіть **install_hub.cmd**. На кожному керованому ПК один раз оновіть агент і імпортуйте його індивідуальне запрошення. Подальші підписані релізи можна завантажувати й роздавати з панелі хаба незалежно від версії прошивки ESP32.

Поточна Windows-публікація зберігається у **windows/agent**. Спільні [вихідні файли агента та його збирач](../esp32-s3/agent/source) використовуються також для контролерної версії.
