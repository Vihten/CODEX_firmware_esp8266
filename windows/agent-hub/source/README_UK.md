# Локальний хаб агентів Windows

Хаб працює на ПК оператора. Агенти на інших ПК самі звертаються до нього по завдання. Тримайте панель відкритою зі станом **Працює**, поки керуєте агентами. Закриття панелі із підтвердженням зупиняє хаб.

## Запуск

1. Розпакуйте весь комплект. Потрібен Python 3.10 або новіший із Tk і доступним через PATH pythonw.exe. Запустіть **install_hub.cmd**, щоб створити ярлик **Хаб агентів** на робочому столі. Для запуску з розпакованої теки відкрийте **start_hub.vbs**. Для запуску з термінала підійде команда `pythonw.exe -B hub_ui.py`.
2. Виберіть підключений мережевий інтерфейс із приватною IPv4-адресою, доступною для керованих ПК. Панель відновлює збережений вибір, інакше пропонує адресу інтерфейсу з основним маршрутом або першу доступну приватну адресу. Типовий порт — **4220**.
3. Натисніть **Запустити хаб**. У заголовку з’являться фактична адреса та порт. Для ярлика з автоматичним запуском додайте `--start` після шляху до `hub_ui.py` або до аргументів `start_hub.vbs`. Панель запустить хаб, якщо доступна одна адреса або точно збігається збережене прив’язування. За неоднозначного вибору вона зачекає на рішення оператора.
4. Якщо брандмауер блокує вхідні з’єднання, адміністратор може виконати на ПК хаба `.\configure_hub_firewall.ps1 -Action Enable -Port 4220` з каталогу комплекту. Для іншого порту вкажіть його число. Для видалення створеного правила використайте `-Action Remove` із тим самим портом. Звичайна робота панелі відбувається від імені користувача.

## Додати комп’ютер

1. Натисніть **Запросити ПК…**. Виберіть назву та ID зі списку офісного чату або введіть вручну вісім шістнадцяткових символів ID та назву. Звірте ID на цільовому ПК. Список чату лише підставляє поля. Реєстрацію запускає оператор.
2. У діалозі збереження виберіть особисту теку. JSON містить окремий секрет доступу для цього агента. Передайте файл власнику відповідного ПК приватно. Якщо запис файлу не вдався, виберіть рядок ПК і натисніть **Зберегти запрошення…**. Це відновить той самий ключ, зокрема після перезапуску панелі.
3. На ПК зі старішою версією спочатку розпакуйте архів Windows-агента й запустіть **update_codex_lan_agent.cmd**. Підтримку хаба додано у версії **20261127180000**. На цільовому ПК з установленим сумісним агентом відкрийте каталог із засобом імпорту й запустіть від імені користувача агента `.\import_agent_hub.cmd "C:\шлях\hub-00AB12CD.json"`, підставивши фактичний шлях. Також можна запустити файл CMD і ввести шлях на запит. Після імпорту приберіть копії запрошення з місць передачі. Перший підтверджений запит агента оновить час зв’язку та версію у списку.
4. Якщо змінилася адреса або порт хаба, збережіть запрошення повторно з новими параметрами і виконайте явну заміну на відповідному ПК через `.\import_agent_hub.cmd -InvitationPath "C:\шлях\hub-00AB12CD.json" -Replace`.

## Оновлення та інші завдання

Початковий реліз лежить у теці **release** поруч із панеллю. Інший архів релізу розпакуйте й натисніть **Вибрати теку…**. Виберіть теку, яка безпосередньо містить **manifest.json** і **package.zip**. Або натисніть **Завантажити з GitHub**. Завантаження відбувається у фоні. Панель зберігає новий вибір після перевірки підписаного релізу. Якщо виникла помилка, чинний вибір і черга завдань зберігаються.

Виберіть рядок потрібного ПК. **Перейменувати…** запитує нову назву, **Оновити агента** показує ціль і теку релізу, а **Видалити агента…** вимагає ввести ID вибраного комп’ютера. Один ПК може мати одне активне завдання. Стежте за стовпцем **Стан**. Завдання в черзі або пропозиція агенту ще очікує результату. Для видалення успіх підтверджує відповідь агента. Стан **Час сплив · результат не підтверджено** означає, що за десять хвилин хаб не отримав підтвердженого результату. Агент міг виконати вже запропоновану команду. Перевірте результат на самому ПК перед повтором.

## Локальні дані

Панель зберігає базу хаба, налаштування та кеш у **%LOCALAPPDATA%\LED Forge\Agent Hub** під обліковим записом оператора. Доступ до теки мають цей користувач, SYSTEM і локальні адміністратори. Сервіс захищає збережені ключі через Windows DPAPI. Окремі експортовані запрошення потрапляють у місця, які явно вибрав оператор.
